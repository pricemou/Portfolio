# Portfolio — Pricemou Fromon Claude

Next.js + Tailwind. Contenu éditable dans `content/fr.json` et `content/en.json`.

```bash
cd site
npm install
npm run dev
```

CV ATS : `public/cv/cv-pricemou-fr.txt` et `cv-pricemou-en.txt`.  
Pour un PDF 1 page : ouvrir `public/cv/cv-pricemou-fr.html` (ou `-en.html`), puis Imprimer → Enregistrer au format PDF.

Déploiement : Vercel (racine = dossier `site`).
